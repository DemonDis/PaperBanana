# Как запустить проект PaperBanana

## Шаг 2: Установка окружения (используется `uv`)
2. Создайте и активируйте виртуальное окружение:
```bash
uv venv 
source .venv/bin/activate 
```

4. Установите все зависимости из `requirements.txt`:
```bash
uv pip install -r requirements.txt
```

## Шаг 3: Настройка API-ключей
Для работы проекту требуются доступ к LLM.

1. Скопируйте шаблон конфигурации:
```bash
cp configs/model_config.template.yaml configs/model_config.yaml
```
2. Откройте файл `configs/model_config.yaml` в любом текстовом редакторе.
3. Укажите хотя бы один API-ключ в разделе `api_keys`. Например, вставьте свой ключ напротив `google_api_key` (для Gemini) ИЛИ `openrouter_api_key`. Оба ключа указывать не обязательно.

*(Дополнительно): Если вы планируете использовать датасет для бенчмарков, скачайте [PaperBananaBench](https://huggingface.co/datasets/dwzhu/PaperBananaBench) и поместите его в папку `data/PaperBananaBench/`.*

## Шаг 4: Запуск приложения
У вас есть 3 способа запустить PaperBanana:

### Вариант 1: Gradio (Рекомендуется для простого использования)
Запускает простой и понятный веб-интерфейс:
```bash
python app.py
```
После запуска перейдите по ссылке (обычно `http://127.0.0.1:7860`), которая появится в терминале.

### Вариант 2: Streamlit (Продвинутый интерактивный интерфейс)
Предоставляет больше настроек для генерации и улучшения изображений:
```bash
streamlit run demo.py
```
Интерфейс откроется в браузере (обычно `http://localhost:8501`).

### Вариант 3: Терминал (CLI)
Если вы хотите запустить генерацию прямо из командной строки:
```bash
python main.py
```
*(Для дополнительных параметров, таких как выбор режима запуска или датасета, смотрите справку `python main.py --help` или `README.md`)*.
